# Hotel Booking Confirmation Page

A booking confirmation page for a French guesthouse, built as a [Frontend Mentor](https://www.frontendmentor.io) challenge. It shows a receipt and a welcome card from the host, plus three info blocks for arrival, Wi-Fi and breakfast.

**[Live demo](https://non1000.github.io/hotel-booking-confirmation-page-main/)**

![Screenshot of the booking confirmation page](screenshots/preview.png)

## About

I built this to practice recreating a more detailed design than my earlier projects: overlapping tilted cards, gradients, custom fonts and icons, and a multi-card layout.

## Built with

- HTML5
- CSS3 (Flexbox, `transform`, gradients, box shadows)
- [Fraunces and other fonts from Google Fonts]

## Features

- Receipt and welcome card tilted and overlapping
- [Cards fan out on hover]
- Gradient welcome card with soft shadows
- Colour-coded info blocks for arrival, Wi-Fi and breakfast
- [Copy button for the Wi-Fi password]
- [Responsive layout / desktop-only]

## What I practised

- Building overlapping, rotated layouts with CSS transforms
- Using gradients and shadows for depth
- Loading and applying web fonts
- Organising assets and relative paths so the site works on GitHub Pages
